# Twelve-source local blind-schema A/B: admission protocol

**Status: source-only preflight implemented; no inference authorized or run (13 October 2026).** This is a development diagnostic for automatic **schema discovery**, not a value-extraction benchmark, product change, or conference-paper result. It compares the pinned NuExtract3 Q4 and the official Qwen3.5-2B BF16 checkpoint on the **same** product parser text. The [schema-only scorer v1 contract](SCHEMA_ONLY_SCORER_V1_CONTRACT.md) is the sole scoring envelope and field-type ontology for this trial; this preflight imports its source-lock, gold and alias validators. A separate receipt records independent human adjudication and source anchors, which the scorer's compact gold JSON deliberately omits.

## One scorer contract, plus separate human and rights receipts

1. **Scorer source lock:** exact UTF-8 JSON with `contract_version: 1` and twelve `sources` entries `{doc_id, source_sha256}`. It has its own precommitted file-byte SHA-256. The preflight checks the whole ID/hash mapping against the current versioned manifest and original bytes. The scorer's `validate_source_lock` rejects duplicate IDs/hashes.
2. **Scorer gold:** exact v1 `{contract_version, source_lock_sha256, documents}` file. Each document repeats `doc_id`, original `source_sha256`, `gold_complete`, `groups: [{group_id, kind}]` and `fields: [{field_id, type, group}]`. The primitive types are exactly `string`, `number`, `integer`, `boolean`, `date`, `datetime`, `currency`, and `identifier`; `group: null` is a scalar. `array[object]` declares a linked repeated parent. The preflight runs the scorer's `validate_gold` and requires **all twelve `gold_complete: true`** for this primary A/B. The scorer can separately diagnose incomplete gold, but that does not admit this model trial.
3. **Scorer aliases:** exact v1 `{contract_version, entries:[{field_id, aliases:[...]}]}` file. The preflight runs the scorer's `validate_aliases`, including normalized collision rejection. The compact alias file has no cohort hash of its own; the separate human receipt binds its exact file-byte SHA-256 to the manifest and scorer source lock. Freeze source-only ordinary terminology before any model output. Exact ID is the primary score; aliases are secondary.
4. **Independent human receipt:** separate externally stored, SHA-pinned JSON with `version: 1`, `status: "adjudicated_source_only"`, exact `source_manifest_sha256`, `eligibility_sha256`, `source_lock_sha256`, `gold_sha256` and `aliases_sha256`, two independent annotator names, an adjudicator, and exactly twelve `sources`. Each source repeats `doc_id`, original SHA-256, `full_source_pass: true`, and **one entry per scorer gold field** with `field_id` and nonempty `anchors: [{locator, quote}]`. The checker verifies structure and binding; a human audit must verify that anchors really resolve in the original and that annotation preceded model output. Keep source-level annotations and identities outside Git. The [human-gold protocol](SCHEMA12_HUMAN_GOLD_AND_SCORING_PROTOCOL_20261013.md) defines the full source, repeated-row and evidence rules.
5. **Rights receipt:** separate externally stored, SHA-pinned JSON with `version: 1`, `status: "cleared_for_local_ai_inference"`, current `source_manifest_sha256` and `source_lock_sha256`, named reviewer, and twelve source entries. Each repeats `doc_id`, original SHA-256, `local_ai_inference_permitted: true`, and the documentary basis. The checker enforces complete binding and affirmative decisions; matching hashes or a self-asserted receipt cannot establish the legal merits. No cloud transfer follows from local rights clearance.
6. **Source-free runtime receipt:** separate SHA-pinned JSON bound to the current manifest, source lock and profile hashes; `status: "source_free_verified"`; both model arms with pinned weight hashes, `loaded: true` and `source_free_smoke: true`. Record software/processor versions, template behavior, 12,288-token context feasibility, latency and resource peaks on synthetic data. This is not a document-quality result.

All locks must be recorded in an immutable pre-inference commit or dated external receipt **before** model replies exist. Rehashing a newly written file on run day does not prove chronology. Raw sources, human annotations, prompts, replies and gold stay outside Git. A profile/prompt/projection change creates a new profile version and hash before inference.

Do not truncate an over-limit source; give it an `over_limit` candidate envelope and zero model calls, while retaining its full-document gold in the twelve-source denominator.
2. Use the profile's common instruction and source view. NuExtract receives its documented `chat_template_kwargs.mode="template-generation"`; Qwen receives the explicit target primitive vocabulary. The profile's predeclared projection maps known NuExtract native tokens such as `verbatim-string -> string`, `date-time -> datetime`, and `email -> identifier` before scorer input. It never chooses a type or field meaning using gold. Unknown types/shapes become a `malformed` source envelope. Preserve every raw reply and projection receipt. Native model sampling differs and is recorded; this is a paired **pipeline** comparison, not a causal weight-only test.
3. Permit at most one schema call per eligible source and model, one at a time, requested seed 42, zero retries, 3,072 output tokens and 300 seconds per call. The absolute maximum is 24 calls for twelve sources. Invalid JSON, duplicate keys, malformed nested lists, timeout, context overflow and a stopped run remain failures in both full denominators. Save exact request/response bytes, hashes, tokens, time, parser version and host resources only in a new I: run directory. Seal all replies before the scorer opens gold. No oracle/reference-schema value arm belongs to this comparison.
4. Project valid templates into the [v1 candidate envelope](SCHEMA_ONLY_SCORER_V1_CONTRACT.md): `{contract_version, source_lock_sha256, documents:[{doc_id, source_sha256, status, groups, fields}]}`. Score exact and predeclared alias branches, primitive type agreement, group-role agreement, linked leaf pairs, repeated-group coverage and strict group hits exactly as implemented. The scorer withholds aggregate precision/F1 if any gold is incomplete, although this preflight requires complete adjudication for the primary A/B. Report per-source and per-format results, character-cap coverage, runtime and reviewer minutes. Twelve sources are too few for a population-quality claim.
5. A schema-only winner is **not** a product winner. It still needs grounded values and complete linked rows, source anchors, HITL reviewer cost, failure/privacy behavior and a separate source-disjoint holdout. A substantive product extraction implementation triggers the user's fresh **2,000 distinct original document** end-to-end gate.
