## Locks that must precede any source prompt

1. **Rights:** an externally stored, SHA-pinned JSON receipt with `version: 1`, `source_manifest_sha256`, `status: "cleared_for_local_ai_inference"`, a named reviewer, and exactly twelve per-source decisions, each with `local_ai_inference_permitted: true` and a basis. A claimed approval must actually address the applicable publisher terms; the checker verifies the receipt structure and hash, not the legal merits. For v2, NICE is not cleared.
2. **Human gold:** independent annotation by at least two people and an adjudicator before inspecting model replies. The SHA-pinned receipt has `version: 1`, the cohort manifest hash, `status: "adjudicated"`, `annotators`, `adjudicator`, and exactly twelve source entries. Each source lists finite, adjudicated `fields` with exact `field_id`, type, `cardinality` (`scalar`, `list`, or `repeated`), optional `group_id`, and at least one source locator/quote in `evidence`. Define which fields are in scope and how optional/blank fields are treated. Keep annotations outside Git with the source corpus.
3. **Alias ontology:** a separate SHA-pinned per-source list of allowed alternative snake_case names keyed by adjudicated gold field ID. It has `version: 1`, the same manifest hash, `status: "frozen"`, and exactly twelve `sources`. Freeze it **before** either model's output exists. Exact ID matching is the primary view; predeclared aliases are secondary. No semantic model judge or post-hoc aliases revise the primary score.
4. **Source-free runtime:** a SHA-pinned receipt bound to the protocol profile and cohort manifest, `status: "source_free_verified"`, and both model arms showing the expected weight hashes, successful load and a synthetic, source-free JSON-template smoke. Verify NuExtract's `/props` and `/apply-template` modes. For Qwen, record the actual serving software/version, processor assets, 12,288-token context feasibility, GPU/RAM peak and Windows behavior. This is not a document-quality result.

The checker accepts each lock only with an explicit file path **and its expected SHA-256**. Hashing a newly created file during the same run does not establish precommitment; the hashes must be recorded in a prior immutable commit or dated external receipt. Every lock binds to the new cohort manifest, so v2 approvals cannot accidentally authorize v3.

2. Use the same common instruction and source view for each arm. NuExtract additionally receives its documented `chat_template_kwargs.mode="template-generation"`; Qwen receives the explicit JSON-template syntax in the common prompt. 3. At most one schema call per eligible source and model, one call at a time, requested seed 42, zero retries, 3,072 output tokens and 300 seconds per call. A 12-source cohort permits at most 24 calls. Invalid JSON, duplicate keys, malformed nested lists, timeouts, context overflow and a stopped run are explicit failures; they stay in both twelve-source denominators. Save the exact request/response bytes, per-call hashes, token counts, elapsed time, parser version and host resource samples only to a new I: run directory. Seal every reply before scoring. No oracle/reference-schema value arm is part of this comparison.
