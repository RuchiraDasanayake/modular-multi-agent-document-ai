# CORD S1 spatial row candidates: frozen source-only v1 protocol

**Scope.** This is a research arm for the 60 sealed CORD development PNGs. It takes the pre-existing RapidOCR **line** graph, SHA-256 `4eb59422fddeb51778150f3cb79ed8f4ff9a34572e4f74b5974d680aaecd4b0d`, and does not perform OCR, call a model, read gold or creator quadrilaterals, inspect reserved sources, or change product extraction. The [line-graph preflight](CORD_S1_OCR_LINE_GRAPH_SOURCE_ONLY_20261013.md) defines original-pixel line nodes and exact text pointers. Its 60-source cohort lock is `48f9af8c04a5ee874c68ccb4c70a5fb81bcfddc508064747779678949103414a`. The geometry rule is [implemented here](../../product_eval/cord_spatial_rows.py); the code's canonical-LF SHA-256 is recorded by the later source-only receipt. **The geometry rule and scorer convention below are fixed before the 60-source run or any gold inspection.**

## Deterministic source rule

1. Recheck the input graph file hash, cohort hash, all 60 development source PNG hashes and dimensions, exact source-ID set, RapidOCR profile/config, and each admitted line graph's text offsets, pixel polygon, locator, and node IDs. An input lock failure aborts the run. An OCR-abstained page produces no candidates.
2. For each line quadrilateral, take its original-pixel axis-aligned bounding box. Connect two lines if their vertical box intersection is at least half the height of the shorter box. Connected components are candidate lanes; all lines in each component are retained, including ones that later abstain.
3. Admit a lane only if it contains **exactly three** lines, every pair passes that overlap rule, and their horizontal box centers occupy distinct `[0,W/3)`, `[W/3,2W/3)`, `[2W/3,W]` bands. Every box width must be at most `0.4W`; the left and middle boxes and the middle and right boxes must have no positive horizontal overlap. Boxes may touch.
4. A passing lane emits `row_id`, `witness_kind="spatial_line_triplet"`, exact `left_node_id`, `middle_node_id`, `right_node_id`, and the union top/bottom pixels. It emits **no semantic field name, item claim, table/cell ID, normalized value, or OCR text copy**. A consumer must dereference the exact IDs against the sealed line graph for raw text, locator, quadrilateral, offsets, and engine/config provenance. The row ID is a digest of source hash, input graph hash, spatial-rule hash, and ordered node IDs.
5. Every non-passing lane retains all its exact node IDs and one fixed abstention reason, applied in this order: `incomplete_lane` (fewer than three); `crowded_lane` (more than three); `transitive_overlap_ambiguous` (three but not pairwise aligned); `duplicate_or_missing_band`; `wide_line`; `horizontal_overlap`. Pages without any passing lane retain `status="abstained"` and `reason="no_unambiguous_triplet"` even if they contain abstained lanes. The output file includes all 60 source pages.

The rule uses only verified image dimensions and RapidOCR line geometry. Text, confidence, source filename, receipt family, creator annotations, and gold are not row-selection features. It deliberately loses coverage when OCR joins fields into one line, when receipts have two spatial columns, when multiple rows overlap vertically, or when headers and totals form valid three-line lanes. Passing geometry establishes only a **candidate** spatial triplet, not item-row truth.

## Frozen later scorer convention

The pure `score_positive_rows` function has no file IO. A later, separately authorized gold evaluation must supply all 60 source hashes, including pages without candidates or positive rows, a list of exact `left/middle/right` raw line texts from ID dereferencing, and the positive annotated rows. For a positive row, the fixed comparison convention requires exact raw `left == item_name` and `right == item_price`; if `item_quantity` is annotated, it additionally requires exact raw `middle == item_quantity`. There is no trimming, case folding, currency cleanup, OCR repair, or post hoc role change. A maximum-cardinality, one-to-one match prevents one candidate from satisfying duplicate gold rows. Positive row recall is matched annotated rows divided by all annotated rows across the 60 sources; if there are no positives the value is undefined. The comparison convention is an evaluation hypothesis, **not** a semantic label emitted by the geometry arm.

This positive-only set cannot establish precision or false-positive rate. A spatial triplet can be a header, total, or unrelated text. No quality claim is permitted from candidate count alone. The receipt will report candidate rows, pages admitting at least one row, all lane abstention counts, and explicit scope limitations. Any relaxed layout rule requires a separate v2 protocol and receipt; this v1 rule must remain unchanged after the source-only result is sealed.
