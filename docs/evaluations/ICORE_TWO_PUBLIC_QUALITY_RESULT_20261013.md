**Completed 13 October 2026.** The frozen [protocol](ICORE_TWO_PUBLIC_QUALITY_PROTOCOL_20261013.md) processed both original public VRDU PDFs through the unchanged product path. It made **three** authenticated `innobot-luna-6` chat requests (two for the registration form, one for the ad-buy form), all with `finish_reason=stop`, zero SDK retries, and **10,538 provider-reported tokens** (6,846 prompt, 3,692 completion). The fourth permitted request was not needed because the ad-buy schema reply failed local validation. Both documents ended `needs_review`; neither was automatically released. The registration result had **11/11 exact source-quoted scalar proposals** and one source-quoted linked cell, yet none matched a gold field ID or row relation under the frozen scorer. Its candidate schema contains 24 fields and the document remains in review for `unapproved_dynamic_schema`. The scorer does not credit semantic aliases: `foreign_principal_name` and `registration_number` are predeclared research aliases for two gold IDs, so 0/6 exact IDs does **not** show that every proposed field meaning is wrong. A separate alias or blinded-human assessment would be needed; benchmark aliases must not become product knowledge. A text quote alone still cannot certify field meaning. The ad-buy route made one schema call and stopped with `invalid_schema_model_response`; it proposed no fields or values. All successful responses reported a normal stop, so the precise structural reason for the invalid schema cannot be determined from the sanitized receipt. The runner saved response hashes and token usage, **not reply bodies**. Fresh ad-buy OCR text also differed from its earlier sidecar hash; this is a diagnostic observation, not evidence of a model defect.

**Decision:** this tiny development test does not justify Luna 6 as an automatic-schema default or any automatic release. It also does not estimate performance on arbitrary documents. The observed failures are exact field-ID alignment and response validity, not network transport; the relative contribution of semantic naming is unresolved. A next model or prompt challenge needs a new frozen, source-disjoint protocol, an exact-output contract, and a review-adjusted cost comparison. Do not rerun these two documents as a fresh quality estimate or silently increase the call cap. No product code changed in this arm, so it does not trigger a new 2,000-source gate.
