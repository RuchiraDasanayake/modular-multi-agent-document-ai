## Frozen call

Run [`product_eval.icore_transport_onecall`](../../product_eval/icore_transport_onecall.py) as a Python module, with an absolute `--receipt` path in an existing directory **outside Git** and one ASCII credential line piped into **non-interactive stdin** by an approved secret source. Never put the key in an argument, command history, log, document, or receipt. The script neither accesses the user's pasted attachment nor searches for a credential. The SHA256 of its canonical Git blob bytes at lock is `daa16cfd694e6f5904e26da8e7f24622fec1f17097673136a62f94804322b3b5`.

The exact one-call arm uses OpenAI Python SDK **2.14.0** with httpx **0.28.1**, both checked before credential read; base URL `https://icore.innobothealth.us/innobot-api/v1`; chat model `innobot-luna-6`; user prompt `Reply with the single word pong.`; `max_tokens=32`; per-call timeout **30 seconds**; `max_retries=0`; redirects disabled. There is one Chat Completions `with_raw_response.create` invocation. It uses no document text, schema, model comparison, DNS/TLS side probe, or automatic retry. A missing credential or version mismatch stops before the call.

The receipt is created exclusively at a fresh outside-Git path. Both that file and stdout contain only JSON with these keys: `exception_class`, `cause_classes` (up to four names), `http_status`, `finish_reason`, `prompt_tokens`, `completion_tokens`, `total_tokens`, `elapsed_ms`, and optional `request_id`. Exception/cause names and finish reasons use fixed allowlists; status/counts are bounded integers; request IDs are accepted only in conservative `req_...` or UUID shapes and rejected if key-like. The script never formats an exception or includes its message, HTTP body, model answer, header collection, or credential. It disables SDK/httpx debug logging. A syntactically plausible request ID can still be provider metadata, so do not publish the raw receipt without review.

Exit **0** means a response reported all three usage counts. Exit **1** means the one call raised an exception, with sanitized class chain/status if available. Exit **2** means the one response omitted at least one usage count; **stop**, keep it unscored, and do not retry. Exit **3** means preflight or receipt creation failed; no conclusion about provider behavior follows. An empty or incomplete receipt after process interruption also provides no provider conclusion. No exit code authorizes a follow-up call in this arm.

Four [offline tests](../../product_eval/tests/test_icore_transport_onecall.py), canonical Git blob SHA256 `13742891d10159f75dd61e6963a1c3974891daad02050a7d9509181fc3dc8193`, exercise a mock exception whose message contains a synthetic secret, a one-call success with response text excluded, absent usage, and request-ID rejection. They passed before this protocol was committed. **No live ICORE call has been made by this diagnostic.**
