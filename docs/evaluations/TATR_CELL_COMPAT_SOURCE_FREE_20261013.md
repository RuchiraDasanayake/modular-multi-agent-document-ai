# Table Transformer cell compatibility: source-free prerequisite

**Status: synthetic compatibility PASS; first-PDF inference NO-GO.** No selected PDF, gold record, model object, model inference, or product extractor was used. This work does not change the 219-row parser denominator or satisfy the separate 2,000-original-source product gate.

## Exact source and scope

`product_eval/tatr_cell_compat.py` calls the staged [asset preflight](../../product_eval/tatr_asset_preflight.py), which rehashes all 14 pinned files, verifies both safetensors byte lengths/hashes and class maps, and requires the exact Microsoft source and MIT model-card bytes. It then executes the exact pinned `postprocess.py` after replacing its single `from fitz import Rect` import in memory. It selects the five pure cell-related function definitions from the exact pinned `inference.py` syntax tree. The repository carries neither a PyMuPDF dependency nor an edited copy of the 893-line upstream postprocessor. This is a research harness; the deliberate `exec` calls run only after the full source hash check. The source root is `I:\DocAI-Benchmarks\tatr-adbuy12-runtime-v1-stage`; model weights are hashed but never loaded.

Pinned Microsoft source: `microsoft/table-transformer@16d124f616109746b7785f03085100f1f6247575`; `inference.py` SHA-256 `cb7b962f9b984de5ba0b24798ac3f977628bba2d7055da2bf6b4545a31b789e1`; `postprocess.py` SHA-256 `a7b3bdf0b0f9ea4b2ccd04bb0acca4bb05b1809d120edf556526a6d976d027db`; MIT notice SHA-256 `c2cfccb812fe482101a8f04597dfc5a9991a6b2748266c47ac91b6a5aae15383`. The [asset receipt](TATR_ADBUY12_ASSET_AND_SOURCE_FREE_PREP_20261013.md) records the model revisions and verified weight hashes. The independent rectangle subset is [tatr_rect.py](../../product_eval/tatr_rect.py); it implements only construction, indexing/iteration, area, intersection and bounding union used by these pinned functions. It does not establish numerical equivalence to PyMuPDF for every malformed or degenerate box. The wrapper rejects nonfinite, zero-area and out-of-image active boxes before calling upstream code.

## Synthetic behavior verified

- Official row/column reconstruction produces a 2-by-2 grid with one truly empty cell: its `cell text` is `""` and its `spans` list is empty. Header flags remain on the top row.
- Official spanning-cell reconstruction occupies two top-row columns while preserving its starting row and assigns the title word once. Native PDFium word tokens and synthetic OCR words populate adjacent cells without duplicate assignment.
- The token contract requires one word per token, finite in-image box, explicit contiguous order, unique source ID and source provenance. Native words retain their original PDF box and must arrive in increasing, nonoverlapping PDFium character ranges; reversed native words fail closed. Scan words additionally require OCR engine, revision and confidence. Invalid order, line-level OCR text, absent provenance, duplicate exact words, out-of-image boxes and mixed native/OCR feeds fail closed. The contract preserves supplied order and does not infer multi-column reading order.
- `Rect` empty-union, area, intersection, touching-edge and bounding-union fixtures pass. The pinned-asset verifier hashes Microsoft source before execution; no source-mutation fixture was run in this cell-compatibility suite.

Validation from the main checkout: `python -m pytest -q product_eval/tests/test_tatr_cell_compat.py` **14 passed** with the pinned asset stage present; `python -m ruff check product_eval/tatr_cell_compat.py product_eval/tatr_rect.py product_eval/tests/test_tatr_cell_compat.py` passed. Outside this host, the official-source fixture explicitly skips when the pinned asset stage is unavailable; the geometry and input-contract tests still run.

## Source/protocol discrepancy

The [frozen research protocol](TATR_ADBUY12_RESEARCH_PROTOCOL_20261013.md) says to apply per-class **0.5** structure thresholds. The pinned Microsoft `objects_to_structures` passes thresholds into `refine_rows` and `refine_columns`, but those two functions do not use their threshold argument; a 0.49-score row with text survives upstream. The research wrapper prefilters every active structure object at 0.5 to honor the frozen protocol. A synthetic test proves the different row result. The protocol now explicitly locks this prefilter before any selected PDF or gold is opened. The eventual runner must retain raw detections and name the deviation; it cannot be described as byte-for-byte official inference behavior. No score-driven choice has been made.

## First-PDF smoke decision

**NO-GO.** This source-free test removes the PyMuPDF import from a bounded cell path and exercises the main cell semantics. Independent review found that distinct grid cells can still have overlapping source boxes after upstream text expansion; the wrapper now rejects any positive-area cell-box overlap and a regression fixture covers it. A scored PDF still needs: a sealed CPU dependency/runtime receipt; a pinned, rights-reviewed word-level OCR path for the two image-only PDFs; a tested crop/rotated-table token transform and page-coordinate overlay; actual safetensors-to-object compatibility on a model output; and a guarded one-PDF-per-process runner. Synthetic cell tests do not establish alignment with document pixels, extraction quality, throughput or operating cost.
