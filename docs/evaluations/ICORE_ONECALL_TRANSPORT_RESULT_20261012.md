# ICORE one-call synthetic transport result

The frozen [one-call protocol](ICORE_ONECALL_TRANSPORT_PROTOCOL_20261012.md) completed one synthetic `innobot-luna-6` Chat Completions request. It returned HTTP **200**, `finish_reason=stop`, and usage of **13 prompt + 5 completion = 18 total tokens** in **1,681 ms**. No document content was sent, no answer text was saved, and no second call was made. This establishes that this key, endpoint, and tiny request worked at that moment. It does **not** explain the earlier public-document `APIConnectionError`, measure reliability or extraction quality, or establish a USD charge.

The code and four offline sanitizer tests were committed as `d6e08c9` before the network call. The exact request used the pinned OpenAI SDK 2.14.0/httpx 0.28.1, `max_tokens=32`, a 30-second timeout and zero SDK retries. The sanitized receipt is outside Git at `E:\DocAI-Benchmarks\icore-transport-onecall-20261012\receipt.json`, SHA256 `6a23499f651962e9a0476e207b30cb708e6fca4d30ddb6166c4d2f781fb79b30`. It contains a provider request ID, which is withheld here, and only the allowlisted metadata in the protocol. `api_cost_usd` and settled charge remain unknown.

The user-provided credential was selected in memory from the pasted attachment and piped through standard input; it was not printed, placed in a command argument, or committed. The one-off PowerShell selection guard had an indexing error that emitted a non-terminating `InvalidOperation`, so the call proceeded without that guard completing. The selected candidate was the unique 47-character key; a read-only post-call check verified that the only longer regex match was this key followed by adjacent pasted text. This operator error did not cause a retry, but the selection command should not be reused. Rotate the exposed credential before any production deployment.

**Decision:** retain ICORE as an opt-in bounded test provider. Do not infer uptime from one success or run a cloud corpus until current pricing, settled usage, a hard spend cap and document-processing terms are available. A real-document trial requires a new frozen protocol; this arm authorizes no follow-up request.
