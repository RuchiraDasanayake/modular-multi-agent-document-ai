## Required gates before the 12-PDF runner

1. **Rights/runtime:** Resolve exact ONNX rights for the hash above and missing wheel notices; build a deterministic OpenCV closure and verify installed `RECORD`/content bytes, not just cached wheel hashes and installed versions. Preserve package, source, model and notice hashes. Pin the three RapidOCR OCR weights and their model notices and verify actual OCR session providers before any document run. This smoke supplied text manually and did not run OCR inference.
2. **Page and table localization:** Freeze PDFium 300-DPI rendering with page size, crop and rotation metadata. A reasonable non-oracle candidate is the already staged MIT TATR detection checkpoint with its fixed 0.5 table threshold and at most five crop pixels of padding. Do **not** use gold boxes or hand-picked crops. Seal the detector revision/checkpoint, resize/box transform, duplicate suppression and behavior when no table is detected, including scans, on source-free fixtures. The current RapidTable preflight has no PDF reader or table detector.
3. **OCR and cell provenance:** Freeze whether to use source PDF words, RapidOCR polygons, or both; prefer one full-page OCR pass only where native words are absent, then transform selected tokens into crop coordinates and record every source token. Test rotations, crop offsets, cell spans, repeated text, duplicate boxes and empty cells on synthetic fixtures. Check HTML physical-cell order against `logic_points` and `cell_bboxes`, then map each local box through table crop and page raster into source-page coordinates. Bounds alone do not prove text-box correctness; ambiguous token/cell mapping fails. Reuse the existing HTML-only score but preserve raw OCR separately for the visual audit.
4. **Execution and stop rule:** Commit a reviewed runner and fixed config before first selected PDF. Launch one PDF per isolated CPU subprocess, sequentially, with no gold path or cloud credentials. Rehash source and runtime. Record raw HTML, boxes, logic, page raster, local-to-page transforms, OCR tokens, parser/error status, process-tree peak RSS and elapsed time in a new absent external output directory. At minimum apply the existing TATR resource floors (6 GiB free host RAM and 4 GiB each free on C: and I: at start; stop below 3 GiB RAM or a 4 GiB disk floor), 8 GiB process-tree RSS cap, 20-page/2-MB source caps, 180-second startup, 600-second first-PDF, 480-second later-PDF, and 3,600-second total cap. A resource failure remains a denominator failure. The first PDF must return all expected pages, at least one table with nonempty cell text and valid page boxes, plus an independently readable source-pixel overlay; otherwise stop and mark the other eleven unattempted.
5. **Sealed scoring:** Hash-seal all conversion outputs and failures before opening gold. Audit the first 20 one-to-one exact matched rows in frozen source order, including duplicate, extra and spanned cells, against independently rendered source pixels. Report every sampled cell verdict and any unresolved ambiguity. Do not infer field-level or autonomous-release quality from parser rows.
