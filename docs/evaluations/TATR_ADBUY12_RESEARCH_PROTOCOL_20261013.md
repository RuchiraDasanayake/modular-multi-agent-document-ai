## Frozen implementation profile

1. Render each PDF page with PDFium at **300 DPI** and record pixel width, height, source PDF page size, crop and rotation. Use the pinned detection checkpoint for full-page table proposals, and the pinned structure checkpoint on crops with **five image pixels maximum padding**. Preserve the [upstream 800/1000-pixel detector/structure maximum resize](https://github.com/microsoft/table-transformer/blob/16d124f616109746b7785f03085100f1f6247575/src/inference.py), then apply this arm's frozen `score >= 0.5` prefilter to each active structure class before cell postprocessing. Retain all raw class scores and boxes; do not select crops with gold labels. The [structure model labels](https://huggingface.co/microsoft/table-transformer-structure-recognition-v1.1-all/blob/7587a7ef111d9dcbf8ac695f1376ab7014340a0c/config.json) are table, row, column, column header, projected row header and spanning cell.
2. Supply page text tokens with `text` and image-space `bbox`, sorted in reading order, as [Microsoft requires](https://github.com/microsoft/table-transformer/blob/16d124f616109746b7785f03085100f1f6247575/docs/INFERENCE.md). For native PDFs, use source PDF words and their boxes; for the two image-only PDFs, use a rights-reviewed, pinned local OCR path. Record token source, text and geometry. The OCR token granularity and native-word extraction implementation are **not yet frozen**; choosing them after looking at a TATR score is forbidden.
3. Safely load the Hugging Face safetensors and produce DETR label/score/box objects. Use a pinned, reviewed adaptation of Microsoft's [`objects_to_structures` and `structure_to_cells`](https://github.com/microsoft/table-transformer/blob/16d124f616109746b7785f03085100f1f6247575/src/inference.py) to align rows/columns, resolve spans, assign each text token at most once, and retain each cell's text, row/column indexes, source tokens and image box. Assign a spanning cell to its starting row for the existing scorer, and retain its full row/column span separately. Hugging Face's object-detection pipeline alone does **not** return filled table cells. Preserve the distinction between missing text and an empty cell.
4. Reproject every table and cell box through the crop, page raster, PDF crop/rotation and page-point transforms to the original PDF page. Reject nonfinite, zero-area, out-of-page, overlapping-grid or ambiguously mapped cells. Emit `ParsedDocument v2` table cells with source-page coordinates only after this check. A quote anchor is allowed only when its exact text can be resolved against retained page text. Box containment is geometry validity, not alignment accuracy.
5. After the first PDF, require successful conversion, at least one table, at least one nonempty cell text with a valid source-page box, and an independently rendered overlay showing the text inside its claimed cell. Otherwise stop, mark the other 11 unattempted, and score the full denominator. After a complete run, independently inspect the first 20 one-to-one exact matched gold rows in frozen order, including every extra or duplicate parser cell. Preserve per-cell visual verdicts. No parser output becomes a released business field without a separate evidence and review gate.

The eventual runner must use CPU/four threads and process one PDF per subprocess, one at a time, into a fresh `I:\DocAI-Benchmarks\tatr-adbuy12-v1` directory outside Git. Preflight floors: 6 GiB available RAM, 4 GiB free C:, 4 GiB free I:. Stop a worker at 8 GiB process-tree RSS, below 3 GiB available host RAM, or below either disk floor. Limit input to 20 pages and 2 MB per PDF. Cap startup at 180 seconds, conversion at 360 seconds per PDF, first worker wall time at 600 seconds, later worker wall time at 480 seconds, and the full run at 3,600 seconds. Save source and artifact hashes, package/notice manifest, every worker log, raw detections, tokens, adapted cells, score and failure receipt. Do not silently retry, change thresholds, or reuse a partial output directory. A GPU run is a separately frozen hardware and cost arm.

The predeclared research continuation bar is **at least 30/219** complete exact-cell rows, at least one strict exact-multiset row, and every audited cell aligned to source pixels. This only warrants a broader, source-disjoint evaluation. Product adoption additionally needs field attribution, evidence/HITL correctness, throughput, operating cost, failure recovery and the user's separate 2,000-distinct-source gate.

## Required work before an executable runner

1. Seal a compatible CPU runtime and provenance for the two safetensors, configs, processor configs, MIT notices, Microsoft postprocessor source and OCR assets. The two model assets/configs/notices have an [asset-only staged verification](TATR_ADBUY12_ASSET_AND_SOURCE_FREE_PREP_20261013.md); installed package closure and OCR assets remain unsealed.
2. Freeze native PDF word extraction and image-only OCR token granularity. Test word order, split/merged OCR lines, duplicate tokens, rotated pages, crop offsets and one-to-one cell assignment on synthetic fixtures plus a source-pixel overlay. The two image-only PDFs cannot be silently excluded.
3. Validate a minimal Hugging Face output adapter against Microsoft's pinned class map and postprocessor, including resize and box-coordinate conventions, spans and header rows. The [source-free harness](TATR_CELL_COMPAT_SOURCE_FREE_20261013.md) now exercises pinned cell functions with a small permissive rectangle replacement, synthetic words, empty cells and spans, and rejects overlapping cell boxes. It has not loaded either model or established source-pixel alignment. The original inference script is built around `.pth` checkpoints; using safetensors still requires actual model-output integration. The original file also imports `fitz.Rect` from PyMuPDF, whose [AGPL or commercial licensing](https://pymupdf.io/licensing) is incompatible with simply copying that dependency into a permissively packaged product. Unit tests alone cannot establish semantic compatibility without a real smoke PDF.
4. Only then commit an inference runner with the fixed thresholds, failure denominator, process/resource guards and source geometry check above. First execution must wait until the active 2,000-source product gate releases host resources.

**Decision:** do not implement a placeholder inference runner that emits plausible rows without verified text/geometry semantics. Current deliverable is a source-locked protocol and an explicit no-go until these four gaps are closed.
