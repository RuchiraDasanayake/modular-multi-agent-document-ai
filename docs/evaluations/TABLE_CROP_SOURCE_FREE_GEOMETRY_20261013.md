# Source-free table crop and page-coordinate prerequisite

**Status: synthetic geometry PASS; selected-PDF inference remains NO-GO.** This helper is shared research code for the TATR and RapidTable parser trials. It does not detect a table, run OCR or a model, change the product extractor, open a selected PDF or gold record, or produce a parser score.

[`table_crop_geometry.py`](../../product_eval/table_crop_geometry.py) accepts a finite, fully in-page detector proposal and freezes an integer page-raster crop with at most five pixels of requested padding. It records the original proposal, actual crop, page size and whether padding was truncated at the page edge. It rejects out-of-page proposals, out-of-crop cell boxes and words that intersect but cross a crop boundary. It maps retained page word boxes into crop pixels, crop cell boxes into page pixels, and then through PDFium's render converter to PDF page coordinates. A word entirely outside the crop returns `None`; a partly cut word produces an explicit error. No box is silently clamped after detection.

The source-free fixtures render a two-word synthetic PDF with a nondefault PDF crop and each of 0°, 90°, 180° and 270° page rotation at 300 DPI. For both words, the tests verify page-to-crop-to-page pixel equality, PDF page-box agreement within one point, and dark source pixels under the claimed local box. They also cover clipped edge padding, a crossing word, out-of-page proposals, excessive padding and a nonfinite cell box. Validation from the main checkout: `python -m pytest -q product_eval/tests/test_table_crop_geometry.py` **6 passed**; Ruff passed.

**Remaining gate:** An actual model detector must produce non-oracle table proposals, a real table crop and a source-pixel overlay from the first selected PDF. Rotated-table orientation inside a page, OCR polygon/word segmentation, multiple table crops, overlapping detections and full-cell attribution are not established by these fixtures. The frozen 12-PDF denominator and separate 2,000-original-source product gate remain unchanged.
